## 2. 🔴 违规（本轮已修复）

   防泄漏铁律；且原回归只扫静态 system 常量拦不住。修复：
   `_redact_fault_names()` 剥离后回显 + 新增
   `test_stage4c_runtime_prompts_no_fault_leakage`（实跑 dover+cf，
   全量扫描 FakeLLM.calls 的每条运行期消息）。

   （'q-trajaudit--ok'）与 `trace_id[-8:]+ev.id` 拼接，实测非 32/16 位
   hex。修复：sha256 派生确定性 hex id，原 id 经 `atap.trace_id`/
   `atap.ev_id` 生存、导入侧恢复原 trace_id（roundtrip 不变）；顺带
   修复：无父省略 parentSpanId、实现 docstring 声明的
   `gen_ai.tool.call.id` 别名、span 命名改 `{operation} {action|agent}`、
   LLM_CALL span kind=CLIENT、meta 有 model_version 时补
   gen_ai.request.model；新增 hex 约束测试。

   exec_range 含下一 trial 的规划步（论文 Table 6 区间不重叠）→ 改为
   止于下一规划步前一位。

   `Outcome.from_dict`；事件 ts 入 `metadata["atap"]["ts"]` 生存。
